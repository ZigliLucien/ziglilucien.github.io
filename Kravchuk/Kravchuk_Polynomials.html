Kravchuk Polynomials

Kravchuk polynomials are, in some sense, simply a different way of viewing the Kravchuk matrix. Take a row in N K, and consider its entries as a function of the column index. This function is a Kravchuk polynomial. Thus every matrix N K of order N defines N+1 Kravchuk polynomials, one for each row, which we denote by N K n (j). I.e.,

Definition.
The nth Kravchuk polynomial of order N, K n (j,N), is determined by the values K n (j,N)= N K nj from the Kravchuk matrix N K.

For example, the Kravchuk matrix of order N=3 defines four Kravchuk polynomials indexed by n=0,1,2,3 and denoted by K n (j,3), where j is an integer variable. For instance, the values of K 2 (j,3) are 3, -1, -1, 3 corresponding to j=0,1,2,3. Once given as a polynomial in j, we extend j to all real values.
